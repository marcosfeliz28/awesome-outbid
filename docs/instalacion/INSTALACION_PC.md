**1 Propósito**

Este documento describe los pasos para preparar, compilar y validar el instalador de Nexora POS para su uso en sistemas de PC Windows. Aborda las acciones básicas necesarias para generar el archivo de instalación.

**2 Pasos**

1.  `pnpm instalador:preparar` para preparar el instalador.
2.  `pnpm instalador:compilar` para compilar el instalador.
3.  `pnpm instalador:validar` para validar el instalador.

**3 Si falla**

Si el comando falla, leer el mensaje de error detenidamente y ejecutar de nuevo el mismo paso correspondiente.
