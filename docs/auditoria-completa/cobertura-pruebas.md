- `pnpm check` ejecuta typecheck, lint, suite Vitest indicada por `vitest.config.ts` y build (`package.json:14-17`). `pnpm verify` corre integración y solo si termina bien corre Playwright (`scripts/verify.mjs:216-219`). El workflow `verify` instala, genera Prisma, migra/siembra PostgreSQL 17, ejecuta `pnpm check` y luego `node scripts/verify.mjs` (`.github/workflows/ci.yml:14-77`); los otros jobs cubren imagen de Render y Windows (`:78-140`).

Los skips localizados son condicionales y visibles (backup/restore, captura térmica, fixture de inventario externo, Nginx/portabilidad Windows y pruebas que requieren red). No los considero una prueba falsa por sí mismos.
