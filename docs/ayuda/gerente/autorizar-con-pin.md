titulo: Autorizar una operación con PIN
rol: gerente
pantalla: Punto de venta o Caja
palabras_clave: [PIN de gerente, descuento, crédito, salida de efectivo]
---

1. Revisa la venta, descuento o salida que solicita autorización.
2. Confirma el motivo con la cajera.
3. Escribe tu PIN personalmente cuando el sistema lo pida.

Si algo sale mal: no compartas el PIN ni cambies montos para evitar el control.
