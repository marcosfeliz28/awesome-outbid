---
titulo: Vender a crédito
rol: cajera
pantalla: Punto de venta
palabras_clave: [crédito, cliente, PIN de gerente]
---

1. Selecciona primero el cliente con F4.
2. Pulsa **Cobrar** y elige **Crédito**.
3. Si el sistema pide aprobación, gerencia escribe su PIN personalmente.
4. Finaliza la venta; el crédito no es dinero cobrado.

Si algo sale mal: sigue el aviso del sistema y no intentes evitar la aprobación solicitada.
