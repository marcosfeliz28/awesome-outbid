---
titulo: Vender a crédito
rol: cajera
pantalla: Punto de venta
palabras_clave: [crédito, cliente, PIN de gerente]
---

1. Selecciona primero el cliente con F4.
2. Pulsa **Cobrar** y elige **Crédito**.
3. Confirma el acuerdo con gerencia.
4. Si el sistema pide aprobación, llama a gerencia.
5. El gerente escribe su PIN personalmente.
6. Finaliza la venta y recuerda que el crédito no es dinero cobrado.

Si algo sale mal: no tramites crédito sin internet ni compartas el PIN de gerencia.
