---
titulo: Cobrar una venta
rol: cajera
pantalla: Punto de venta
palabras_clave: [cobrar, efectivo, tarjeta, transferencia, pago mixto]
---

1. Pulsa **Cobrar** o F12.
2. Elige la forma de pago y escribe el monto.
3. Completa los campos visibles de tarjeta o transferencia.
4. Pulsa **Agregar pago**.
5. Para pago mixto, agrega otro pago hasta que **Pendiente** sea RD$ 0.00.
6. Pulsa **Finalizar venta** una sola vez y espera la confirmación.

Si algo sale mal: conserva el carrito y lee el aviso antes de intentar otra vez.
