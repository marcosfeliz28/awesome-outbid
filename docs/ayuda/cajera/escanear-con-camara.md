---
titulo: Escanear un producto con la cámara
rol: cajera
pantalla: Punto de venta
palabras_clave: [cámara, escanear, código de barras]
---

1. Busca el botón de cámara junto a **En espera**.
2. Toca el botón de cámara.
3. Apunta al código de barras del producto.
4. Confirma que el producto correcto aparezca antes de agregarlo.

Si algo sale mal: busca el producto por nombre o código y avisa si la cámara sigue fallando.
