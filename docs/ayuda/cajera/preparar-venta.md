---
titulo: Preparar una venta
rol: cajera
pantalla: Punto de venta
palabras_clave: [buscar producto, carrito, cliente]
---

1. Busca el producto por nombre o código, o escanéalo.
2. Confirma la talla, el color o el tono.
3. Toca el producto y revisa cantidad, precio y existencia.
4. Selecciona el cliente con F4.
5. Si no existe, pulsa **Nuevo cliente aquí mismo** y guarda su nombre.
6. Revisa el total antes de cobrar.

Si algo sale mal: busca por código o usa menos palabras.
