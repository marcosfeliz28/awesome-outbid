---
titulo: Revisar los respaldos
rol: dueña
pantalla: Configuración > Respaldos
palabras_clave: [respaldo, Google Drive, restauración]
---

1. Revisa el estado y la fecha de **Último respaldo bueno**.
2. Si aparece **Hay que reconectar**, pulsa **Conectar con Google**.
3. Si está conectado, pulsa **Respaldar ahora** para crear una copia inmediata.
4. Espera a que termine y vuelve a comprobar el estado mostrado.

Si algo sale mal: lee el error mostrado; si no carga el estado, recarga la página.
