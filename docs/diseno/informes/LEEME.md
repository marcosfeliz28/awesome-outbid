# Maqueta de informe amigable A4

`MAQUETA_INFORME_A4.svg` es el insumo visual para las piezas de exportación. Usa marcadores entre corchetes, no datos de la tienda.

Incluye: portada y periodo, explicación en lenguaje claro, cuatro cifras clave, gráfica con ejes y leyenda textual, tabla de detalle, guía de lectura y pie paginado.

Paleta de impresión: tinta #182033, violeta #7255D9, esmeralda #13A886 y grises; mantiene contraste sin depender de color. No usa fuentes web ni servicios externos, por lo que es compatible con la versión sin internet. Al implementar el PDF/Excel, la API debe reemplazar sólo los marcadores con la misma fuente de datos de la pantalla y respetar permisos/caja ciega.
