# Tu primera venta

1. Abre tu caja: menú «Caja» → «Abrir caja» y escribe el efectivo inicial.
2. Entra a «Punto de venta».
3. Busca el producto por nombre o código de barras (tecla F2) y agrégalo. Si tiene variantes (sabor, talla, color), elige la correcta.
4. Si hace falta, elige el cliente (tecla F4).
5. Pulsa «Cobrar» (tecla F12) y elige la forma de pago: efectivo, tarjeta, transferencia, nota de crédito o crédito. Puedes combinar varias.
6. Pulsa «Finalizar venta» e imprime o comparte el recibo.

Consejos:
- F8 pone la venta en espera para atender a otra persona.
- Si un descuento pasa el límite permitido, el sistema pide el PIN de un gerente.
- Las ventas quedan en «Ventas», con su recibo en PDF.
