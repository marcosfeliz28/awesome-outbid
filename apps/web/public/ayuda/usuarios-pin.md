# Usuarios y PIN

Crear un usuario (administración):
1. «Configuración» → pestaña «Usuarios y permisos» → «Crear usuario».
2. Elige el rol, escribe el nombre, el usuario para entrar, la contraseña y un PIN de 6 dígitos.

Para qué sirve el PIN:
- Cambiar de vendedora rápido: menú de tu nombre (arriba a la derecha) → «Cambiar de usuario con PIN».
- El PIN de un gerente aprueba lo que pasa de los límites: descuentos grandes, una caja que no cuadra o un vale de caja.

Buenas prácticas:
- Cada persona usa su propio usuario y su propio PIN. No los compartas.
- Para cambiar tu contraseña: menú de tu nombre → «Cambiar mi contraseña».
- Si alguien deja de trabajar contigo, pulsa «Desactivar» en su usuario («Configuración» → «Usuarios y permisos»).
