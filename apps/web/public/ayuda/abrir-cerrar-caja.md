# Abrir y cerrar la caja

Abrir:
1. Menú «Caja» → «Abrir caja».
2. Escribe el efectivo inicial. El sistema sugiere lo que dejaste en tu último cierre; si pones menos, explica por qué en la nota.

Durante el día:
- «Movimiento» registra entradas o salidas de efectivo (por ejemplo, un pago a un suplidor). Regístralas en el momento, no al final.

Cerrar:
1. Cierra primero el lote del verifón (mira la guía «Cuadre y lote del verifón»).
2. Menú «Caja» → «Cerrar y arquear».
3. Cuenta el efectivo por billetes y monedas, escribe la tarjeta declarada y lo que entregas.
4. Si algo no cuadra, el sistema te pide el motivo y, si hace falta, el PIN de un gerente.
5. Imprime el «Cuadre de Caja».
