# Anular y devolver una venta

Anular (la venta no debió existir: duplicada, error de pago o de artículo):
- Vendedora: en «Ventas», busca la venta y pulsa «Solicitar anulación» con el motivo. La administración la aprueba o rechaza en «Solicitudes de anulación».
- Administración: en «Ventas», pulsa «Anular» y explica el motivo.

Devolver (el cliente trae el artículo):
1. Abre tu caja.
2. En «Ventas», busca la venta y pulsa «Devolver».
3. Elige el artículo, el motivo y el método de reembolso (efectivo, tarjeta, transferencia o nota de crédito).
4. Marca «Reingresar al stock vendible» solo si el producto se puede volver a vender.

Todo queda en la bitácora. Nada se borra.
