# Obsidian Lumina R2 · ChatGPT

Maqueta visual de la Contrapropuesta Ejecutiva Ronda 2. Es una referencia de
diseño responsive; no contiene autenticación, llamadas de API ni credenciales.

## Dirección

- Lujo silencioso y adulto: composición, materiales sobrios, tipografía amplia y
  luz con una función concreta.
- Acción principal esmeralda; violeta para selección y firma de marca.
- Acceso primero a 390 px.
- Contraseña web, clave numérica y PIN de caja tratados como flujos distintos.
- Sin efectos continuos; respeta `prefers-reduced-motion`.
- Imagen hero original generada por ChatGPT para esta propuesta.

## Archivos

- `nexora-obsidian-lumina-r2-chatgpt.html`: maqueta independiente.
- `assets/prisma-nexora-r2.webp`: pieza hero optimizada, 46 KB.
- Las capturas desktop y móvil se generan en esta misma carpeta.

## Nota de implementación

La maqueta usa CSS nativo para expresar la dirección. La aplicación real debe
reutilizar sus tokens y componentes compartidos y conservar autenticación,
permisos, reglas fiscales, APIs y base de datos.
