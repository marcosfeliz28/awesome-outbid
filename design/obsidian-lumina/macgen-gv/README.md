# Nexora POS · Macgen + GV Makeup Studio

Aplicación de Obsidian Lumina a la operación real de Grupo Macgen y su empresa
hermana GV. Son maquetas estáticas para abrir localmente, no flujos conectados.

## Sistema visual

| Rol | Color |
| --- | --- |
| Obsidiana base | `#05050A` |
| Superficie oscura | `#121521` |
| Macgen / acción | `#43E3B1` |
| GV Makeup / agenda | `#C98BFF` |
| Advertencia | `#F7C760` |
| Riesgo | `#FF8FA3` |

Tipografía: **Manrope** para lectura y **DM Mono** para dinero, conteos y datos
operativos. Títulos 28--40 px escritorio / 24--30 px móvil; cuerpo 14--16 px;
acciones táctiles mínimo 44 px. Todos los montos se alinean con `tabular-nums`.

## Pantallas

1. `01-vender.html`
2. `02-cobrar.html`
3. `03-cierre-ciego.html`
4. `04-tablero-duena.html`
5. `05-gv-cursos-citas.html`

La dirección es mejor que una plantilla SaaS genérica porque da prioridad a la
decisión inmediata: venta y total para cajera, excepción/alerta para dueña, y
agenda/cobro pendiente para GV. Macgen usa esmeralda, GV violeta, y el lenguaje
de superficies, espaciado, contraste y números es uno solo.
